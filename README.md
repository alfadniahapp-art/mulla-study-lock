# Mulla Study Lock

تطبيق أندرويد مبني بـ Flutter لقفل التطبيقات تلقائيًا وفق الجدول المدرسي، مع قائمة استثناءات للتطبيقات التعليمية، ودعم كامل للجدولة بعد إعادة التشغيل.

## ✨ الميزات الأساسية
- جدولة كاملة: بدء وإيقاف تلقائي حسب أيام الأسبوع والوقت.
- استمرارية بعد إعادة تشغيل الهاتف.
- قائمة تطبيقات مسموح بها (الآلة الحاسبة، القاموس، تطبيقات المدرسة).
- شاشة حظر مخصصة بالكامل.
- وضع صارم يمنع تجاوز الحظر إلا بكلمة مرور.

## 🛠️ التقنيات
- Flutter (Android فقط في المرحلة الأولى)
- `app_blocker` package للجدولة وخدمة إمكانية الوصول
